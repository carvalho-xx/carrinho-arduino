# 🤖 Carrinho Robô Arduino com Bluetooth e Sensor

Projeto de um carrinho robô controlado por aplicativo via Bluetooth e com freio automático de obstáculos usando sensor ultrassônico.



## ⚙️ Funcionalidades

* **Controle por Bluetooth:** Recebe comandos de um smartphone via módulo HC-05/06.
* **Movimentação Completa:** Anda para frente, para trás, gira e faz curvas suaves (diagonais) usando controle de velocidade (PWM).
* **Desvio de Obstáculos:** Usa um sensor ultrassônico para parar automaticamente se houver um objeto a 20 cm ou menos à frente.
